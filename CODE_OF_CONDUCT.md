# Code of Conduct

The Python Code Intelligence & Performance Workbench participates in **Winter of Code Social (WOCS) 2026**, organised by Code Social.

## 1. Applicable Policy

All project contributors, maintainers, mentors, and community members participating in WOCS-related project activities are expected to adhere to the official **[Winter of Code Social Code of Conduct](https://woc.codesocial.tech/code-of-conduct)**, which is based on the Contributor Covenant.

The Code of Conduct defines expectations for welcoming, inclusive, professional, and harassment-free collaboration across all project spaces, including:

- GitHub issues, pull requests, and code reviews.
- Project and community discussions.
- Related Discord communication channels.

## 2. Reporting and Enforcement

Unacceptable behavior, harassment, discrimination, or abusive conduct should be reported directly and privately through the official Code Social reporting channels:

- Submit reports privately through the dedicated Code of Conduct reporting channels on the **[Code Social Discord Server](https://discord.gg/MSTNyRSPYW)**.
- Or email reports privately to the official Code Social community address: **codesocialcommunity@gmail.com** (as specified in the official WOCS FAQ).
- **Do not post incident reports or personal details in public GitHub issues, pull requests, or open chat channels.**

WOCS programme administrators and organizers are responsible for investigating reported incidents and determining fair and appropriate enforcement measures.

## 3. Scope of Support

Code of Conduct moderation and programme-level escalations are handled by Code Social / WOCS organizers. Technical questions, bug reports, feature discussions, and pull request reviews should be directed to the repository's GitHub issues and pull requests in accordance with [CONTRIBUTING.md](CONTRIBUTING.md).
